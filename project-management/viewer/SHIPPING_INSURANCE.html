Shipment and insurance operations plan

Workflow: quote → declared value → choose eligible built-in or approved third-party policy → show underwriter, covered events, exclusions, limits, deductible and claims rules → customer acceptance → tamper-evident label → pickup → tracking → receiving photo/video → custody scan → expert inspection → secure return → delivery confirmation. Partner selection: verify licensing and coverage, high-value limits, geography, loss claims, API capabilities, secure facilities, packaging standards, return coverage, dispute handling. Controls: dual custody handoff, photo evidence, parcel weight, exception alerts, segregated storage, loss incident runbook, clear responsibility for declared value and claims. MVP fallback: manually arranged shipping with approved insured service and explicit human review; no UI promise of automatic insurance until integration exists. Operational KPIs: transit losses, claims closure time, intake SLA, handling cost, inspection time, customer disputes.
