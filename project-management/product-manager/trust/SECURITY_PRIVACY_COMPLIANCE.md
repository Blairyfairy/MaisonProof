# Trust, security, legal and compliance gate matrix
| Control | Required proof | Owner to appoint | Current state |
|---|---|---|---|
| Authentication expertise | Credential matrix and independent QA | Head of review | Not verified |
| Signed records | Crypto design, key rotation, tamper tests | Security | Not implemented/verified |
| Privacy | Data inventory, notices, retention, deletion, DPIA as applicable | Counsel/DPO | Needs review |
| Consumer claims | Approved wording, demo disclosures, endorsements | Counsel | Needs review |
| Shipping/insurance | Carrier/underwriter contracts, limits, exclusions | Ops/legal | No contracts evidenced |
| Payment | PCI scope, processor terms, refund policy | Finance/security | Needs review |
| Trademarks & imagery | Rights audit, source attribution and permissions | Counsel | Needs review |
| Accessibility | WCAG 2.2 AA test report | Design/QA | Not audited |
| Incident response | Tabletop exercise, notification triggers | Security/ops | Not exercised |
| Platform distribution | Shopify/WooCommerce/Magento review | Engineering | Not approved |

Legal requirements vary by jurisdiction. This is a planning checklist, not legal advice or proof of compliance.
