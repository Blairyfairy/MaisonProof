## Operating rule
A green authenticated seal is never merchant self-attested. It requires a real MaisonProof reviewer decision, item binding, revocation-aware validation, and a functioning verification record. Remote review may be inconclusive and require physical inspection. No unverified insurance or brand partnership claims.

## Delivery sequence
13 two-week sprints (Sprint 0–12), **illustrative planning estimate**; capacity and calendar dates must be confirmed. Use backlog IDs to trace requirements → design → implementation → tests → release.
