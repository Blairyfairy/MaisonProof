# MaisonProof for Drupal 10/11

Copy `maisonproof_verify` to `web/modules/custom/`, enable the module, then configure `/admin/config/services/maisonproof`. Place the **MaisonProof authentication badge** block and enter a SKU. The block only appears when the service reports `authenticated`. For Drupal Commerce, automatic per-product SKU resolution and inventory syncing are future work.
