# MaisonProof GitHub Pages showroom

The root `index.html` is a standalone static product demonstration. It is **not** a live authentication service. All records, counts, and certificates shown on the website are fictional and labeled as demonstrations.

## Publish

1. Create a GitHub repository and upload the **contents** of this directory to its root.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select your default branch, **/(root)**, and save.
5. Wait for GitHub Pages to provide your site URL.

No build system, secrets, API credentials, or paid hosting are required for the static showcase. GitHub Pages does not run Python/PHP: deploy the API and store integrations separately.

## Interactive elements

- Four platform tabs
- Customer verification badge with four selectable statuses
- Sample certificate dialog
- Responsive navigation and interface mockups
- Repository file links

The demo must never be presented as an actual verification or guarantee of authenticity.
