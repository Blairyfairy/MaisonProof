# Shopify embedded admin interface — branding starter
The Shopify theme extension renders the branded customer-facing status block.
An embedded Shopify Admin application **cannot be installed from this theme extension alone**. It requires a hosted app, Shopify OAuth, sessions, an App Bridge integration, and the appropriate Admin API permissions.
`brand-dashboard.html` is a responsive visual reference for the embedded app UI; it is not an OAuth implementation or live dashboard. Use the shared assets and tokens when implementing the actual app.
Do not use this mockup to assert that authentication is operational.
